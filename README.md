# Machine_Learning_Introduction

## What is Machine Learning?

**Machine Learning (ML)** is a branch of Artificial Intelligence (AI) that allows computers to learn from data and make predictions or decisions without being explicitly programmed for every task.

### Simple Example

If we give a machine learning model many examples of houses with their prices, the model can learn the relationship between features such as:

* House size
* Number of bedrooms
* Location
* Age of the house

After learning from the data, the model can predict the price of a new house.

---

## How Machine Learning Works

A typical machine learning process consists of:

1. **Collect Data** – Gather relevant data.
2. **Clean Data** – Remove errors and handle missing values.
3. **Prepare Data** – Convert the data into a suitable format.
4. **Train the Model** – Allow the algorithm to learn patterns from the data.
5. **Test the Model** – Evaluate how well the model performs on unseen data.
6. **Make Predictions** – Use the trained model on new data.

---

## Types of Machine Learning

There are three main types of machine learning:

### 1. Supervised Learning

In supervised learning, the model learns from **labeled data**.

The input data and the correct output are provided during training.

**Examples:**

* Predicting house prices
* Detecting spam emails
* Predicting whether a customer will buy a product

**Common algorithms:**

* Linear Regression
* Logistic Regression
* Decision Trees
* Random Forest
* Support Vector Machines
* K-Nearest Neighbors

---

### 2. Unsupervised Learning

In unsupervised learning, the data does not contain predefined labels. The model tries to discover patterns or groups in the data.

**Examples:**

* Customer segmentation
* Grouping similar documents
* Finding unusual patterns

**Common algorithms:**

* K-Means Clustering
* Hierarchical Clustering
* Principal Component Analysis (PCA)

---

### 3. Reinforcement Learning

In reinforcement learning, an **agent** learns by interacting with an environment.

The agent receives:

* **Reward** for good actions
* **Penalty** for bad actions

The goal is to learn a strategy that maximizes the total reward.

**Examples:**

* Game-playing AI
* Robot navigation
* Autonomous systems

---

## Important Machine Learning Terms

### Dataset

A **dataset** is a collection of data used for training and evaluating a machine learning model.

### Features

**Features** are the input variables used by a model to make predictions.

For example, for house-price prediction:

```text
Size
Bedrooms
Location
Age
```

### Label

A **label** is the target or expected output.

For example:

```text
Features → House Size, Bedrooms, Location
Label    → House Price
```

### Model

A **model** is the learned mathematical representation of patterns in the data.

### Training

**Training** is the process of teaching a model using available data.

### Prediction

A **prediction** is the output generated by a trained model for new data.

---

## Training and Testing Data

A dataset is commonly divided into:

* **Training Set** – Used to train the model.
* **Validation Set** – Used to tune and select the model.
* **Test Set** – Used to evaluate the final model.

Example:

```text
Dataset
   |
   +-- Training Data
   |
   +-- Validation Data
   |
   +-- Test Data
```

## Machine Learning vs Traditional Programming

### Traditional Programming

```text
Rules + Data → Output
```

The programmer provides the rules explicitly.

### Machine Learning

```text
Data + Expected Output → Model
```

The model learns the rules or patterns from the data.

Then:

```text
New Data + Trained Model → Prediction
```
